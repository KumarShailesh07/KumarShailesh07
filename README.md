### From Data Analytics → AI-Powered Analytics

An end-to-end healthcare analytics project that evolved from traditional **data analysis and business intelligence** into an **AI-powered natural-language analytics application**.

The project combines:

**Excel → Power Query → SQL → Power BI → Python → GenAI → Streamlit**

### 📊 Phase 1 — Healthcare Data Analytics

**Tech:** Excel • Power Query • SQL Server • Power BI • DAX • Python

Analyzed approximately **55,500 healthcare records from 2019–2024** covering:

* Patient demographics
* Medical conditions
* Hospitals and doctors
* Admissions
* Billing
* Insurance providers
* Medications
* Test results
* Length of stay

### 🔎 Key Analysis

* Cleaned and transformed raw healthcare data using Power Query
* Performed advanced SQL analysis using CTEs, aggregations, joins and window functions
* Built interactive Power BI dashboards
* Created DAX measures and calculated metrics
* Performed data-quality and duplicate analysis
* Identified patterns across admissions, billing, conditions and demographics
* Converted analytical findings into business-focused recommendations

### 📌 Key Findings

| Metric                        |         Result |
| ----------------------------- | -------------: |
| 🗂️ Healthcare Records        |     **55,500** |
| 💰 Total Billing              |   **$1.417B+** |
| 💵 Average Billing            | **$25,539.31** |
| 🏥 Average Stay               | **15.51 days** |
| 👨 Male Patients              |     **50.04%** |
| 👩 Female Patients            |     **49.96%** |
| 🔎 Potential Duplicate Groups |        **534** |

### 🤖 Phase 2 — Healthcare AI Analyst

**Tech:** Python • Streamlit • Gemini • LangChain • DuckDB • Pandas • SQL

After completing the analytics phase, I wanted to take the project one step further:

> **What if a user could simply ask the healthcare data a question in natural language instead of writing SQL?**

That idea became the **Healthcare AI Analyst**.

The application allows users to ask questions such as:

💬 *What is the average billing amount?*
💬 *What are the most common medical conditions?*
💬 *How many total admissions are there?*

### ⚙️ AI Application Workflow

```text
Natural Language Question
          ↓
Relevance Check
          ↓
Knowledge Base / Cache
          ↓
SQL Generation when required
          ↓
Read-Only SQL Validation
          ↓
DuckDB Query Execution
          ↓
Query Result
          ↓
Business-Friendly AI Answer
          ↓
Streamlit Interface
```

### 🛡️ Engineering & Safety Features

* Natural Language → SQL generation
* Read-only SQL validation
* Blocks potentially destructive SQL operations
* Knowledge-base caching for validated questions
* Reduced unnecessary LLM calls
* DuckDB-based analytical execution
* Error handling and fallback responses
* Interactive Streamlit chat interface
* SQL and query-result inspection

* 📊 Tables generated approximately **$17.7K loss**
